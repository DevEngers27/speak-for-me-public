## §3 首个场景与示例数字

原文：existing committed spend is $4,000 against a $5,000 total budget. The full change request costs $1,400 … consider a $900 first phase with some work deferred（R:241）；during approval, reduce the total budget to $4,800. The old $4,900 proposal must become non-executable（R:245）。

### 数字表（金额以整数美分计，R:279）

| 量 | 值 | cents | 出处 |
| --- | --- | --- | --- |
| 总预算 | $5,000 | 500000 | R:241, R:400 |
| 已承诺支出 | $4,000 | 400000 | R:241, R:416 |
| 初始余量 | $1,000 | 100000 | 派生 |
| 全量变更 | $1,400 | 140000 | R:241 |
| 一期（部分工作延后） | $900 | 90000 | R:241, R:416 |
| 一期后承诺合计（原文称 "$4,900 proposal"） | $4,900 | 490000 | R:245, R:334, R:400 |
| 下调后总预算 | $4,800 | 480000 | R:245, R:400 |
| 下调后余量 | $800 | 80000 | 派生 |

### 算术核对（原文没有逐步写出，以下为派生）

- 全量：400000 + 140000 = 540000 > 500000 → 超预算，不可行。这正是"考虑一期 + 延后部分工作"的理由。
- 一期：400000 + 90000 = 490000 ≤ 500000 → 可行。
- 下调：490000 > 480000 → 旧方案不可执行；任何新方案的增量必须 ≤ 80000。
- 原文没有给出能否在 $800 内凑出满足必需范围的组合，因此"重新协商成功"与"向人请求取舍"两条分支都可能出现（R:416 写的是 "renegotiate or escalate"）。
