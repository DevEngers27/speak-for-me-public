## §4 系统原则

来源是 README "Team rules before development"（R:34-53）以及散落在全文中的原则性语句。团队规则里属于系统原则的部分（财务权限、隐私、执行边界、不伪造）几乎原样成立；属于团队协作或黑客松节奏的部分丢弃。
